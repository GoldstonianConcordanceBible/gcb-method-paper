# Mirror → Water → Fire Whitepaper (GCB Concordance OS)

This repository formalizes the Mirror → Water → Fire interpretive framework as a structured concordance operating system:
- **Mirror**: canonical anchoring (indexing)
- **Water**: cross-link graph logic (typed, evidenced links)
- **Fire**: constrained interpretation (safety + non-assertion)

## What’s inside
- `/paper` – the full whitepaper (sectioned Markdown)
- `/spec` – the operational spec + guardrails
- `/schemas` + `/examples` – agent-compatible JSON schemas and examples
- `CITATION.cff` + `zenodo.json` – DOI-ready metadata for Zenodo releases
- `figshare.metadata.json` – metadata scaffold for Figshare deposits

## How to cite
See `CITATION.cff`.

## Release workflow
1) Update `VERSION`
2) Update `CHANGELOG.md`
3) Create a Git tag: `vX.Y.Z`
4) Create a GitHub Release (Zenodo can mint DOI per release if connected)
