# 2. Ethiopian Canon Contextualization

## 2.1 Purpose
MWF supports multiple canon families by treating canon membership as metadata rather than as a polemic.

## 2.2 Canon Families
A canon family label does not claim superiority; it records:
- tradition context
- textual witness
- usage scope (liturgical/academic/devotional)

## 2.3 Context rules
Water Phase MUST:
- state canon family
- state edition/witness if known
- avoid asserting “originality” without evidence
- allow parallel anchoring (same theme across canon families) while preserving provenance
