# 5. Agent-Compatible Metadata Design

Agents need stable schemas, not vibes.

## 5.1 Required repo artifacts
- CITATION.cff for citation tooling
- zenodo.json for GitHub→Zenodo metadata
- deterministic schemas in /schemas
- examples for each schema in /examples
- versioning (VERSION file + tags)

## 5.2 Metadata fields that matter for agents
- canonical identifiers
- structured references
- stable link typing
- evidence references
- review status
- license clarity
- non-assertion clause reference
